# Система ясности — Аудиоклуб (блок для Тильды)

Страница аудиоклуба «Почему ты такой» (Vue 3 + Tailwind, присланная одним html-файлом), переупакованная для вставки на Тильду одним блоком **HTML-код (T123)**. Меню и футер — на стороне Тильды, в блоке их нет.

## Ссылки

- Превью (GitHub Pages): https://elenasamanchuk.github.io/sistema-yasnosti-club/
- Ассеты (jsDelivr): `https://cdn.jsdelivr.net/gh/ElenaSamanchuk/sistema-yasnosti-club@main/assets/`
- Сайт клиента: https://sistemayasnosti.com (Тильда, меню T228 fixed 59px — якоря страницы рассчитаны на него)

## Вставка на Тильду

Три блока **HTML-код (T123)**, вставлять в этом порядке (папка `tilda/`):

| Порядок | Файл | Размер | Что внутри |
| --- | --- | --- | --- |
| 1 | [`1-css.html`](tilda/1-css.html) | 35 КБ | шрифты, preload первых картинок, стили |
| 2 | [`2-html.html`](tilda/2-html.html) | 0,1 КБ | контейнер блока |
| 3 | [`3-js.html`](tilda/3-js.html) | 112 КБ | приложение: рисует разметку и оживляет её |

**Сначала запушьте `main`.** Сами блоки содержат разметку и стили целиком, но картинки грузятся с jsDelivr, то есть из репозитория. Пока новый файл не в `origin/main`, на странице будет `alt` вместо картинки — а jsDelivr ещё и запомнит 404 на несколько минут. Сборка предупреждает о таких файлах в конце вывода.

1. Откройте страницу в редакторе Тильды.
2. Добавьте три блока **HTML-код (T123)** подряд.
3. В каждый вставьте **целиком** содержимое соответствующего файла.
4. Отступы всех трёх блоков — 0 сверху и снизу.
5. Опубликуйте страницу.

Разметку рисует блок 3, поэтому в редакторе Тильды блок 2 выглядит пустым — так и должно быть. Порядок блоков не критичен: скрипт дожидается появления контейнера, но правильный порядок даёт более быструю отрисовку.

Альтернативы одним блоком:

- [`all-in-one.html`](tilda/all-in-one.html) — всё сразу, 147 КБ;
- [`external.html`](tilda/external.html) — 0,9 КБ, CSS и JS подгружаются с jsDelivr. Самый лёгкий вариант, работает только после пуша в `main`; jsDelivr подхватывает файлы за 2–10 минут.

Важно: после каждой пересборки заново вставьте файлы в блоки и опубликуйте страницу — имена файлов в CDN содержат хеш содержимого.

## Что сделано с присланной страницей

- убраны `<header>` (меню) и `<footer>`, у корня снят `min-h-screen`;
- 8 картинок из base64 (1,4 МБ) → WebP на jsDelivr (~430 KB), hero и печать пластинки — с `preload`, остальные `loading="lazy"`;
- CSS Tailwind снят с `@layer` и целиком обёрнут в `.sya` — стили не протекают на блоки Тильды, а её глобальные правила не ломают блок;
- JS без `type="module"`, в IIFE (никаких глобальных `const` рядом с jQuery Тильды), точка монтирования `#sya-club-app`;
- плеер в hero: кнопка play/pause, музыка стартует только по клику, точка прогресса и волна двигаются во время воспроизведения. Трек — Эрик Сати, «Гимнопедия №1», фортепиано Robin Alciatore, public domain (Musopen / Wikimedia Commons), `assets/audio/satie-gymnopedie-1.mp3` (3,3 МБ, грузится только после нажатия play);
- плавное появление блоков и элементов при прокрутке (IntersectionObserver, уважает `prefers-reduced-motion`);
- плавный скролл по якорным ссылкам (`#price`, `#format`, `#topics`, `#faq`) — своей анимацией, с поправкой на липкое меню Тильды (оно измеряется на лету: 59 px в десктопе, 50 px в мобилке) плюс 16 px воздуха. Ловятся клики по всей странице, так что заработают и пункты меню Тильды, если их повесить на эти якоря;
- одинаковый вертикальный ритм: у всех семи секций отступ сверху и снизу `clamp(48px, 7vw, 80px)`. В присланной сборке часть секций была `section` (60/100), часть `section-sm` (40/60), а у hero верхний отступ был 20/80 против нижнего 60/100 — под собственную шапку, которой на Тильде нет;
- убраны два больших провала в мобилке: в «Теперь будет иначе» перед кнопкой «Узнать подробнее» (было 72 px, стало 44) и в «Авторе аудиоклуба» между цитатой и фотографиями (было 66 px, стало 42);
- неразрывные пробелы после предлогов/союзов (встроенный типограф) и снятие точек в конце абзацев;
- «Теперь будет иначе», пункт 03 — описание уже, чтобы «теория» переносилось;
- плашка в hero: вместо даты «Старт продаж — 07 сентября» постоянное «Доступ по подписке»;
- свою картинку можно подставить вместо присланной: файл `source/img/<роль>.jpg` (или `.png`, `.webp`), где роль — имя из таблицы `IMAGE_ROLES` в скрипте сборки: `hero-player`, `vinyl-mark`, `recognition-band`, `author-1…3`, `faq-photo-1…2`. Замена переживает новые сборки от разработчика и видна в таблице картинок при сборке;
- всё на выходе минифицировано esbuild: без комментариев и пустых строк, кириллица не экранируется. CSS 34 КБ, JS 112 КБ.

## Обновление контента

0. Один раз после клонирования: `npm i` (нужен esbuild для минификации).
1. Новый файл от разработчика положить в `source/` (имя с датой, например `audioclub-2026-09-10.html`).
2. Собрать:

```bash
cd ~/Projects/sistema-yasnosti-club && npm run build
```

`npm run build` = `node scripts/build-tilda.mjs --music=assets/audio/satie-gymnopedie-1.mp3 --bot='https://t.me/tribute/app?startapp=s15wd'`. Дополнительные опции: `--ref=<sha>` (закрепить CDN на коммите), `--clean` (удалить старые версии файлов).

3. Закоммитить и **запушить в `main`** — до вставки в Тильду, иначе новые картинки отдадут 404.
4. Заново вставить `tilda/1-css.html` и `tilda/3-js.html` в свои блоки T123 и опубликовать страницу (`2-html.html` меняется редко — сверьтесь с `git status`).

Если картинку уже успели запросить до пуша, jsDelivr держит 404 в кеше. Сбросить:

```bash
curl -s "https://purge.jsdelivr.net/gh/ElenaSamanchuk/sistema-yasnosti-club@main/assets/img/<файл>.webp"
```

Скрипт падает с понятной ошибкой, если структура присланной сборки поменялась (имена компонентов, разметка плеера) — тогда нужно обновить регулярки в `scripts/build-tilda.mjs`.

## Локально

```bash
cd ~/Projects/sistema-yasnosti-club && npm run serve
```

http://localhost:5567 — превью `index.html`. Проверочные страницы в `preview-tmp/` (не в репозитории): три блока отдельно, три блока внутри копии страницы Тильды, сравнение с оригиналом.

## Файлы

| Файл | Назначение |
| --- | --- |
| `source/*.html` | Присланные сборки (как есть) |
| `source/img/<роль>.jpg` | Свои картинки вместо присланных (необязательно) |

| `assets/img/*.webp` | Картинки для CDN (имя = роль + хеш) |

| `tilda/1-css.html`, `2-html.html`, `3-js.html` | Три блока T123 по порядку |
| `tilda/all-in-one.html` | То же одним блоком |
| `tilda/external.html` | Блок T123, CSS и JS с jsDelivr |
| `index.html` | Превью (GitHub Pages) |

## Известные плейсхолдеры в присланной странице

- ссылки на кнопках покупки в hero и в блоке «Что входит»: в присланной сборке `https://t.me/your_bot_username`, сборка подставляет ссылку оплаты Tribute `https://t.me/tribute/app?startapp=s15wd`. Меняется флагом `--bot=` (в `package.json` она в одинарных кавычках — `?` в URL иначе съест шелл);
- ссылки меню/футера «Отзывы», «О создателе», «Личный кабинет» вели на `#` — в блок не входят.
